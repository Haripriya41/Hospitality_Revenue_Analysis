 🏨 Hospitality Revenue Analysis
Hotel revenue analysis of 135,000+ bookings across 4 cities using SQL, Power BI, Tableau and Python
End-to-end analysis of 135,000+ hotel bookings across 4 cities to find where revenue is being lost and how to recover it.

 Business Problem
Which cities, booking platforms and booking patterns drive revenue, and how much potential revenue is lost to cancellations and no-shows?

 Dataset
- 134,590 bookings across 4 cities (April to July)
- Key fields: booking status, booking platform, city, room category, revenue generated, revenue realized, ratings

 Tools
SQL (MySQL)  • Power Query • Power BI (DAX) 
 • Excel

 Approach
1. Data cleaning: cleaned and validated the data using SQL, Pandas and Power Query
2. SQL analysis: joins, CTEs and window functions for revenue, occupancy and cancellations
3. Dashboards: built interactive dashboards in Power BI 
4. Insights: identified revenue leakage and made recommendations

 Key Metrics
| Metric | Value |
|---|---|
| Total bookings | 134,590 |
| Revenue realized | ₹1,709M |
| Revenue generated | ₹2,000M (approx.) |
| Occupancy | 57.87% |
| Cancellation rate | 24.83% |
| Weekday / weekend bookings | 84,365 / 50,225 |
| Checked out / cancelled / no-show | 94,411 / 33,420 / 6,759 |

 Key Findings
- Revenue realized was about ₹300M lower than revenue generated, around 15% of potential revenue, lost to cancellations and no-shows
- Cancellation rates were similar in every city (about 25% in Delhi and Bangalore), so the problem is company-wide
- Direct booking channels (online and offline) earned little compared with third-party platforms
- Weekdays produced most of the revenue [add your own insight here]

 Recommendations
- Introduce tighter cancellation terms
- Grow direct bookings to recover part of the lost revenue
